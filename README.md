# Devansh Kuchipudi — Portfolio

A single-page, minimalist developer portfolio built with plain HTML and CSS (no frameworks, no build step). Dark theme with a monospace accent and a subtle animated line sweeping across the page.

## Sections

- **Hero** — name, short intro, links to Work and Contact
- **Work** — selected projects
  - Spam & Smishing Detector (Python, FastAPI, DistilBERT, SHAP, SQL)
  - Kalakriti Resin Studio web platform (HTML, CSS, JavaScript, React)
  - Open slot reserved for a future project
- **About** — background summary and skills grouped by Languages, Web & Frontend, Backend & Data, and Mobile
- **Ventures** — YouTube channel (psychology & evolutionary biology) and Kalakriti Resin Studio
- **Contact** — email, GitHub, and LinkedIn links

## Tech

- HTML5 and CSS3 only — no JavaScript frameworks or external dependencies
- Responsive layout that collapses to a single column on mobile
- Respects `prefers-reduced-motion` for accessibility

## File

- `index.html` — the entire site (markup + styles in one file)
